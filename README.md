Вариант №8
Дисциплина: Конфигурационное управление

## 1. Назначение

Программа представляет собой эмулятор командной оболочки
UNIX-подобной операционной системы.

Программа реализует:

- графический интерфейс;
- разбор командной строки;
- команды ls и cd;
- команду exit;
- запуск через параметры командной строки;
- startup-скрипты;
- виртуальную файловую систему;
- команды tail, uniq и tac;
- изменение владельца с помощью chown;
- обработку ошибок.

Все изменения виртуальной файловой системы выполняются
только в оперативной памяти.

## 2. Требования

Python 3.10 или новее.

Используются только стандартные библиотеки Python.

## 3. Запуск

Linux/macOS:

    chmod +x run.sh
    ./run.sh

Windows:

    run.bat

## 4. Запуск с VFS

    ./run.sh --vfs vfs/sample.csv

или:

    python3 -m src.main --vfs vfs/sample.csv

## 5. Запуск startup-скрипта

    ./run.sh --vfs vfs/sample.csv --script scripts/startup.txt

При возникновении первой ошибки выполнение startup-скрипта
останавливается.

## 6. Команды

### ls

Показывает содержимое текущего каталога.

    ls
    ls /home

### cd

Переходит в каталог.

    cd /home
    cd user
    cd ..

### tail

Выводит последние 10 строк файла.

    tail readme.txt

### uniq

Удаляет последовательные повторяющиеся строки.

    uniq readme.txt

### tac

Выводит строки файла в обратном порядке.

    tac readme.txt

### chown

Изменяет владельца элемента VFS в памяти.

    chown admin readme.txt

### exit

Завершает работу эмулятора.

    exit

## 7. Виртуальная файловая система

Источник VFS представляет собой CSV-файл.

Формат:

    path,type,content,owner

type может принимать значения:

- file
- dir

Содержимое файлов хранится в CSV в кодировке Base64.

После загрузки данные преобразуются в объекты
VirtualFileSystem и используются только в оперативной памяти.

Исходный CSV-файл при работе программы не изменяется.

## 8. Параметры запуска

--vfs PATH

Путь к физическому CSV-файлу виртуальной файловой системы.

--script PATH

Путь к startup-скрипту.

При запуске программа выводит параметры,
с которыми была запущена.

## 9. Обработка ошибок

Обрабатываются следующие ситуации:

- отсутствие VFS-файла;
- неправильный формат CSV;
- некорректный тип VFS-элемента;
- ошибка Base64;
- отсутствие файла;
- отсутствие каталога;
- попытка cd в файл;
- неизвестная команда;
- неправильное количество аргументов;
- ошибка startup-скрипта.

## 11. Этапы разработки

### Этап 1

Создан GUI, parser, команды ls и cd, exit,
а также обработка ошибок.

### Этап 2

Добавлены параметры --vfs и --script,
вывод параметров запуска и startup-скрипты.

### Этап 3

Добавлена виртуальная файловая система
с загрузкой из CSV и Base64.

### Этап 4

Реализованы ls и cd для VFS,
а также tail, uniq и tac.

### Этап 5

Реализована команда chown,
изменяющая владельца элемента VFS только в памяти.

## 12. Пример

После запуска:

    $ ls

может быть получен результат:

    home/

После:

    $ cd /home/user

команда:

    $ ls

выведет:

    docs/
    readme.txt

Команда:

    $ chown admin readme.txt

изменит владельца файла в текущей VFS.
